# Circuit Module Documents (English Translation)

This package contains the English-translated versions of the original circuit explanation documents.

## Notes

- All document titles, body text, and filenames have been translated into English.
- Images and diagrams were kept unchanged.
- The translated files are provided in `.docx` format for convenient editing and review.

## File Overview

### 1. STM32F103C8T6 Microcontroller Core Circuit
Introduces the STM32F103C8T6 core board, including its features, pin functions, reset circuit, oscillator circuit, internal architecture, and application background.

### 2. 5V Power Supply Circuit
Explains the 5V DC power input circuit, including the DC jack, power indicator LED, current-limiting resistor, switch control, and filtering capacitor.

### 3. 8050 Relay Control
Describes how an 8050 transistor is used to drive a relay, including switching logic, current amplification, and the status indicator LED.

### 4. 8050 Buzzer Alarm and LED
Introduces the active buzzer alarm circuit driven by an 8050 transistor, with an LED used as a visual alarm indicator.

### 5. E18-D80NK Infrared Obstacle Avoidance Sensor
Covers the operating principle, parameters, wiring, and application scenarios of the E18-D80NK infrared photoelectric obstacle detection sensor.

### 6. ESP32-CAM Camera Module
Summarizes the main features of the ESP32-CAM module, including Wi-Fi, Bluetooth, camera support, low-power operation, and IoT applications.

### 7. ESP8266 Wi-Fi Integrated Module
Explains the ESP8266 Wi-Fi module, including communication modes, hardware interfaces, power supply requirements, and common use cases.

### 8. Through-Hole Resistor Voltage Divider Circuit
Introduces the basic voltage divider principle, typical resistor selection method, and its use for reducing measured voltage before ADC sampling.

### 9. JDY-31 Bluetooth Module
Describes the JDY-31 Bluetooth serial communication module, including features, parameters, interface pins, and usage scope.

### 10. JR6001 Voice Playback Module
Introduces the JR6001 voice playback module, including audio format support, USB update method, serial control, and typical applications.

### 11. Push Button Circuit Design
Explains the push-button input circuit used for human-machine interaction, including default logic levels and button-trigger behavior.

### 12. MQ-3 Alcohol Sensor Module
Describes the MQ-3 alcohol sensor, including sensing principle, warm-up requirement, output characteristics, and typical application scenarios.

### 13. OLED 0.96-inch Display Module
Introduces the OLED display module, including display characteristics, interface pins, resolution, and communication options.
